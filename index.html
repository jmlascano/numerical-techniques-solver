LU Decomposition Solver — AMAT 105

Enter a square matrix A and a vector b. The solver writes A = LU using Anton’s method, then solves Ly = b and Ux = y. Every number is an exact fraction.

Input

A
b

Entries may be integers (3), decimals (-0.25), or fractions (-3/4). Leave b empty to find only L and U.

Solution

Method: Anton, Elementary Linear Algebra, 10th ed. — reduce A to row echelon form U with leading 1s, using no row interchanges. L holds each pivot on its diagonal and each eliminated value below it. Run the tests.
